# Quieter Enderal Death Sound

A small audio replacement for Enderal: Forgotten Stories Special Edition that makes the player death sound quieter.

## Install

Install the archive with Vortex, or copy the `sound` folder into the Enderal Special Edition `Data` directory. If another mod also replaces this audio file, choose which version should take priority in your mod manager.

## Included file

`sound/fx/enderal/music/enderal - death.wav` replaces the corresponding Enderal death sound asset.

## Compatibility

This package contains only the replacement audio asset and does not include plugins or scripts. It was prepared for Enderal Special Edition. It has not been tested across other versions or alongside other mods that edit the same file.

## Uninstall

Disable or remove the mod in Vortex. If installed manually, remove the replacement file and restore the original from a clean game installation or backup.
